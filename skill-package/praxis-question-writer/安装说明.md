# praxis-question-writer · 安装说明

Praxis 5001（美国小学全科教师资格考试）原创出题技能。让 agent 按官方大纲批量生成
高质量、版权安全的练习题（对接 Triumph 备考工具的题库格式）。

## 安装（3 步）

1. 解压 `praxis-question-writer.zip`
2. 把解压出的 **`praxis-question-writer` 文件夹**（内含 SKILL.md 和 references/）放到你的 agent 技能目录：

| Agent | 目录 |
|---|---|
| Hermes | `C:\Users\<你>\.hermes\skills\` |
| Claude Code | `C:\Users\<你>\.claude\skills\` |
| 通用 / DSH | `C:\Users\<你>\.agents\skills\` |
| 其他支持 markdown skill 的 agent | 对应的 skills 目录 |

3. 重启 agent 会话（或让它重新扫描技能）

## 验证是否装好

- Hermes：在会话里问"你有哪些 skills？"应看到 `praxis-question-writer`
- 或直接问："请简述 praxis-question-writer 的 §0 流程"——能回答 = 装好了

## 使用（按顺序）

1. **首次**：执行"指令模板 0"——让 agent 下载官方 Study Companion、提取大纲，
   保存到 `references/official-blueprint-5001.md`（一次即可，后续复用）
2. **试跑**：指令模板 1（8 题小批量）看质量
3. **批量**：指令模板 3（四科首轮 ~76 题）

> 完整指令模板见 Triumph 项目 `Hermes出题指令模板.md`。

## references/ 说明

- `question-schema.json` —— 输出格式模板（题目 JSON schema，含版权字段）
- `official-blueprint-5001.md` —— 【运行后生成】官方大纲提取文件（agent 下载后写入此路径）

## 关键规则（skill 内置，装好后无需记）

- **先官方大纲，后出题**（§0 强制）：内容类别、每类题数以 ETS Study Companion 为准
- **100% 原创**：禁止复制 ETS 真题、回忆题、第三方题库
- 输出 JSON 必须带 `blueprint` 字段（official / approximation）和 `source.type: original`
