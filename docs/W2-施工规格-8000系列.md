## 四、题目 schema v1 硬要求

**21 字段**（顺序即 field_order），详见 `content-infra/item-schema-v1.md`：
```
id · series · test_code · subject · content_domain · skill · difficulty ·
question_type · stimulus · stem · choices · correct_answer · explanation ·
distractor_explanations · source_basis · review_status · reviewer · version ·
duplicate_hash · created_at · updated_at
```

**关键约束**：
- `series` = `"8000"`；`test_code` = 整数 8002/8003/8004/8005
- `correct_answer` = **选项文本，不是索引**（与顺序无关）
- `question_type`：`single-select` | `multiple-select`（**仅 8002–8005**，每批约 10%）
  + 8003 另可含 `numeric-entry`
- **`distractor_explanations` 是硬约束**：新题**必须逐干扰项写解析，缺一条即退回**。
  键 = 干扰项选项原文（与 choices 逐字一致），**不含正确答案**，恰好 3 条。
  写法：60–200 字符，用第三人称动词直接点错误（如 `Subtracts before distributing…`），
  **禁止** "This is incorrect because…"、复述题干、空泛套话。
- `duplicate_hash` 算法：`normalize(stem)` + `normalize(choices)` 升序 → `join("|")` → SHA-256
  （normalize = 小写 + 移除全部非 `[a-z0-9]` 字符）
- `source_basis`：有官方依据写 `official-source`，纯专家判断写 `expert-judgment`，**不得伪装**
- `review_status`：新题一律 `draft` 起步，人工复核后改 `human-reviewed`
- `created_at` / `updated_at`：ISO-8601 UTC，`Z` 结尾

**multiple-select 体例**（仅 8002–8005）：
- 题干用 `Which TWO of the following...`，**禁止** "Select all that apply"
- A–E 共 5 项，正确**恰好 2 项**，干扰 3 项
- `correct_answer` 为 string[]，顺序无关
